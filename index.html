规范速查

BEM 块

全小写短横线。允许 block、block__element、block--modifier、block__element--modifier。只保留一层 __ 和一层 --。

  • ✓ cart / cart__item / cart--compact
  • ✗ cart__item__price / ProductCard / product_card

状态类

SMACSS 状态：is-*、has-*，后接小写短横线。

  • ✓ is-active / has-error
  • ✗ Is-Active / is-

命名空间

l- 布局、g- 全局、u- 工具类。

  • ✓ l-grid / g-container / u-mt-8
  • ✗ L-grid / u-

JS 钩子

禁止在 CSS 中为 js-* 编写样式。钩子只放在 HTML 上。

  • ✓ HTML 上使用 js-submit-btn
  • ✗ .js-submit-btn { }

选择器权重

嵌套最多 3 层（伪类、@media、@supports、@include 不计）。禁用 ID。复合选择器最多 3 段。

  • ✓ .cart .cart__item.is-selected
  • ✗ #app / .a .b .c .d

SCSS 命名

变量、mixin、function 一律 kebab-case。

  • ✓ $color-primary / text-truncate
  • ✗ $ColorPrimary / TextTruncate
