CSS 选择器命名规范检测

依据《HTML 页面 CSS 选择器命名规范》v1.0，批量检测类名是否符合小写短横线、状态前缀、JS 钩子、语义命名等规则。支持类名列表、HTML 片段与 SCSS 选择器三种输入。

推荐模型：页面类 + 模块类 + 结构类 + 原子工具类 + 状态类 + js-* + data-*

输入

支持批量粘贴类名，按行或空格/逗号分隔

检测结果

0 合计
0 通过
0 警告
0 不合规
粘贴内容后点击「开始检测」，或使用「填入示例并检测」

规范速查

基础命名

小写英文 + 短横线；禁止驼峰、下划线、拼音、无意义名、纯视觉名。

  • ✓ product-card
  • ✗ productCard / tijiao-btn / box1 / red-title

状态类

统一 is-* / has-*，禁止裸 active、show、error。

  • ✓ is-active / has-error
  • ✗ active / show / error

JS 钩子

事件绑定使用 js-* 或 data-*，不依赖样式类；业务数据写入 data-*。

  • ✓ js-submit-btn
  • ✗ 用 mt20 / f16 绑定 JS

职责分层

page-* 页面作用域；模块类标识业务区；结构类放在模块内；原子类处理通用表现。

  • ✓ page-product-detail
  • ✓ verify-modal / card-body / mt20

缩写

仅使用通用缩写 btn / img / desc / nav；禁止 prd / vfy / mdl。

  • ✓ submit-btn
  • ✗ prd-list / vfy-modal

插件类

Slick / PerfectScrollbar / iconfont 等保持原样，覆盖样式限制在模块作用域内。

  • ✓ .verify-thumb-list .slick-current
  • ✗ 全局 .slick-current
